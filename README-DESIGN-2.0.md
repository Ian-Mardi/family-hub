# Family Hub Design 2.0

This package focuses on a full visual refresh and welcome-site overhaul while retaining the existing app/backend structure.

## Design changes
- Premium light/dark-inspired visual design with deeper contrast, restrained gradients, and refined surfaces.
- Main navigation: Home, Messages, Calendar, Family AI, More. Gallery is now accessed from More.
- The Family AI tab remains in the primary navigation.
- Welcome page has four navigable product pages: Home, Features, Privacy, and Get started.
- Home welcome page includes a scroll-driven 3D-perspective product mockup that transforms with scroll progress, plus floating UI panels.
- Feature and privacy pages use responsive layouts; reduced-motion preference disables the transform transition.

## Install
Use the existing Family Hub installation steps in `README-REDESIGN.md`. This design package does not require a new Supabase migration.

The welcome-page mockup is illustrative rather than a live rendering of the app, and the privacy page is product messaging, not a substitute for a formal privacy policy.
